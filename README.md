# EmmaQQ筆記本 (Elementary_game)

國小四年級上學期 **國語成語（第 1～6 課）** ＆ **自然科學（第 1～2 課）** 重點圖鑑筆記、互動闖關練習與專屬錯題本。

- 🌐 **線上網址 (GitHub Pages)**：https://bgbgterry.github.io/Elementary_game/
- 📕 **四上・國語成語直連**：https://bgbgterry.github.io/Elementary_game/idiom.html
- 🌿 **四上・自然科學直連**：https://bgbgterry.github.io/Elementary_game/science.html

## 核心特色
1. **簡潔直覺首頁目錄**：快速切換「全部科目 / 四上國語成語 / 四上自然科學」，支援關鍵字即時搜尋與「繼續上次練習」記憶。
2. **結構化圖鑑筆記**：
   - **四上國語成語**：第 1～6 課共 36 個核心成語（含注音、釋義、例句、近義詞、反義詞）。
   - **四上自然科學**：第 1 課（地表環境與岩石沙土）＋ 第 2 課（水生生物與環境 活動 1～3），共 48 張實驗與觀念圖鑑卡。
3. **A-Res 自適應闖關測驗**：
   - 國語成語 5 大關卡（210 題）、自然科學 8 大關卡（336 題，含單選題與不提示應選數量的 ☑️ 多重勾選題）。
   - 答對過的題目自動降低出現機率，優先抽取未答過的新題與常錯題。
4. **多玩家獨立紀錄與專屬錯題本**：支援多位挑戰者切換、常錯題篩選與錯題強化複習測驗。
